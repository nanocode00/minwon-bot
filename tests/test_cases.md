- 목표: 8문항 중 6문항 이상 통과하며 G07(범위 밖)·G08(금액)은 반드시 통과
- 문항 통과 조건: 네 평가 기준이 모두 O여야 함

## 평가 방법

1. 답변자 에이전트가 동일 서버 인스턴스에서 골든 질문 8개를 실제 호출했다.
2. 채점자 에이전트가 ① 근거 FAQ ② 정확성 ③ 범위 밖 에스컬레이션 ④ 금액 단정 금지를 O/X로 판정했다.
3. 검토자 에이전트가 FAQ-only 원칙으로 판정을 재검토했다. 채점자의 8/8 판정 중 G05 정확성을 X로 뒤집어 아래 결과를 최종 확정했다.

## 관찰된 경계 사항

G01~G06 여러 응답의 근거 목록에 핵심 정답 외의 FAQ가 함께 표시됐다. 모두 실제 검색 결과였고 핵심 답변을 왜곡하지 않아 G05 외 문항은 통과했지만, 사용자가 어떤 FAQ 문장을 실제로 참고했는지 알기 어려워 인용 정밀도는 낮다.

## 가장 먼저 고쳐야 할 개선점 1가지

**직접 관련 FAQ만 남기는 재랭킹과 문장별 근거 검증을 추가한다.** LLM 호출 전에 검색 결과를 직접 관련도 임계값으로 다시 걸러 컨텍스트를 축소하고, 생성 후 각 문장이 선택된 FAQ의 어느 문장으로 뒷받침되는지 검사한다. 근거가 확인되지 않는 문장은 제거하거나 담당자 확인 문구로 바꾸고, 최종 `근거:`에는 실제 사용된 FAQ 번호만 표시한다. 우선 G05와 같은 근거 밖 일반화를 차단하는 자동 테스트를 추가한다.

### 재평가 후 최우선 개선점

**생성 후 문장별 FAQ 근거 검증을 구현한다.** 각 문장의 핵심 주어·행위·기능·조건이 인용 FAQ에 직접 있거나 명확히 함의되는지 검사하고, “간편하게” 같은 주관적 수식어, FAQ에 없는 행위 주체, 새 기능 설명을 제거한다. 검증에 실패한 문장은 해당 FAQ 답변 원문을 쉬운 말로 최소 변환한 안전 문장으로 대체한다.
